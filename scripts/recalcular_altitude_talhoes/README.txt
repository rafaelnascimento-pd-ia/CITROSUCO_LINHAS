===============================================================================
   SCRIPT: recalcular_altitude_talhoes.py

1. O QUE ESTE SCRIPT FAZ:
-------------------------------------------------------------------------------
Recalcula a altitude (Z) de cada vértice do polígono do talhão a partir do MDT, computando centróide 3D e min_z, max_z, mean_z.

2. COMANDO PARA EXECUTAR NO TERMINAL:
-------------------------------------------------------------------------------
python scripts/recalcular_altitude_talhoes/recalcular_altitude_talhoes.py -i "caminho/pasta_input" -m "caminho/mdt.tif" -o "caminho/pasta_output"
