1. O QUE ESTE SCRIPT FAZ:
-------------------------------------------------------------------------------
Script de pós-processamento em lote para recortar/interseccionar linhas com o talhão, projetar altitude (Z) do MDT nas novas geometrias e recalcular estatísticas espaciais.

2. COMANDO PARA EXECUTAR NO TERMINAL:
-------------------------------------------------------------------------------
python scripts/interseccionar_e_recalcular_lote/interseccionar_e_recalcular_lote.py -i "caminho/pasta_input" -m "caminho/mdt.tif" -o "caminho/pasta_output"
