1. O QUE ESTE SCRIPT FAZ:
-------------------------------------------------------------------------------
Extrai estatísticas de elevação Z (min_z, max_z, mean_z, centróide Z) de um MDT raster exclusivamente para geometrias de polígono.

2. COMANDO PARA EXECUTAR NO TERMINAL:
-------------------------------------------------------------------------------
python scripts/herdar_altitude_mdt_poligonos/herdar_altitude_mdt_poligonos.py -i "caminho/poligonos.shp" -m "caminho/mdt.tif" -o "caminho/saida.shp"
