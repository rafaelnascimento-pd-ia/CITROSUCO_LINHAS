===============================================================================
   SCRIPT: mesclar_mdts.py

1. O QUE ESTE SCRIPT FAZ:
-------------------------------------------------------------------------------
Script para unir/mosaicar múltiplos rasters de MDT (GeoTIFF) de voos diferentes em um único arquivo raster unificado.

2. COMANDO PARA EXECUTAR NO TERMINAL:
-------------------------------------------------------------------------------
python scripts/mesclar_mdts/mesclar_mdts.py -i "caminho/mdt_voo1.tif" "caminho/mdt_voo2.tif" -o "caminho/mdt_unificado.tif"
===============================================================================
