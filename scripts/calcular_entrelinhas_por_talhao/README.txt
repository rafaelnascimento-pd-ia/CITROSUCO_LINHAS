===============================================================================
   SCRIPT: calcular_entrelinhas_por_talhao.py
===============================================================================

1. O QUE ESTE SCRIPT FAZ:
-------------------------------------------------------------------------------
Script de pós-processamento geográfico para gerar as linhas centrais das entrelinhas de plantio individualmente por talhão, aplicando um buffer de 4 metros e salvando os resultados segmentados.

2. COMANDO PARA EXECUTAR NO TERMINAL:
-------------------------------------------------------------------------------
python scripts/calcular_entrelinhas_por_talhao/calcular_entrelinhas_por_talhao.py -i "caminho/pasta_entrada" -o "caminho/pasta_saida"
